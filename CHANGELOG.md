# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [1.1.0] — 2026-11-14

Первая публичная версия.

### Добавлено

- Пресет агента **Kotlin Android** для проектов Android Studio: разведка проекта, правила Kotlin,
  Compose/XML, Room, DI, корутин и Flow, сборка только затронутого модуля.
- Панель **Kotlin Android** у нижнего края левой боковой панели: профиль экономии токенов,
  переключатель журнала самоулучшения, команды Gradle одним нажатием.
- Журнал уроков `.dsh/kotlin-android-lessons.md` в проекте: включается и выключается по просьбе
  пользователя, читается в начале задачи, дописывается в конце.
- Словари `ru`/`en` для заголовка и описания бандла.
- Документация: README (ru + en), CONTRIBUTING, MIT-лицензия, CI-проверка синтаксиса и JSON/YAML.
